## 文書の対象の版

文書の対象は、その文書と一緒にチェックアウトした版です。
`main` には未リリースの変更も含まれます。
配布済みの版を運用するときは、対応する Git タグの文書を参照し、更新前にリリースの説明を確認してください。
提案と過去の検証結果は、それぞれの状態を記載した資料です。
現在の版で実装済みであることは、現行の仕様で確認します。

## 必要な説明の探し方

上の表から目的を選び、対象の手順や仕様の節を開きます。
実装を変更するときは、開発上の約束と対象の検査の条件を先に確認します。
判断の根拠が必要なときは、話題の履歴の入口から対象の記録を選びます。
`docs/.ignore` により、`rg` による `docs/` の通常の検索は現行の文書を対象にします。
過去の判断を確認するときは、選んだ履歴のディレクトリを明示して検索します。
