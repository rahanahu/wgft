# 2026-09-21: web-ui

- ダッシュボードのルール一覧とヘッダの全体ヘルスも部分更新する(2026-09-21、10.1 節):自動更新の対象はエージェント一覧と警告バナーの 2 つだけだった。
  ルール一覧の状態欄(適用状態・理由・拒否数)とヘッダの全体ヘルス(エラー件数を含む要約)はページを開いた時点のまま固定され、ルールが後から error になっても復旧しても、操作者は再読み込みするまで気づけなかった。
  GET /ui/rules と GET /ui/health を、既存の GET /ui/agents・GET /ui/warnings と同じ形(依拠する読み取りが失敗すれば 500 を返し、捏造した値は描かない。
  10.5 節)で追加し、#rules セクションとヘッダの #health 要素に data-refresh を付けた。
  ルール一覧のグループの折りたたみは、group-toggle の click listener を初回描画時にしか束縛していなかったため、単純な innerHTML の差し替えでは部分更新のたびに開閉状態と listener の両方を失う。
  app.js に、#rules を差し替える前にグループ名ごとの開閉状態を読み、差し替えた後に listener を束縛し直してから状態を復元する処理を足し、この崩れを防いだ。
  ホストの単体テストで、GET /ui/rules・GET /ui/health が完全なページに埋め込まれているのと同じ断片を返すこと、依拠する読み取りの失敗で 500 になること、data-refresh 属性が付くことを確かめた。
  未確認:実ブラウザでの見た目と、5 秒間隔の連続した部分更新の間にグループの開閉状態が保たれ続けることは、単体テストとテンプレートの目視確認に留め、スクリーンショットや手での操作では確かめていない
