# 2026-09-17: control-plane

- 他テーブルの DNAT のポートが読めない規則を警告する(2026-09-17、公開前レビューの指摘):6.1 節の DNAT の検査で、ポートが multiport や読めない無名 set、未知の式の形で判定できない規則は、それまで黙って読み飛ばし、wgft の DNAT(`dstnat - 1`)が知らずに勝っていた。
  判定できる規則だけを拒否対象にし、判定できない規則は Finding として警告する扱いに改めた

- 登録トークンをエージェントの生死に紐付ける(2026-09-17、公開前レビューの指摘):同じ名前に未使用の登録トークンが複数残ると、片方で登録した後にもう片方で登録すると SQLite の PRIMARY KEY 違反で 500 が返る不具合と、エージェントを削除した後も削除前に発行した未使用トークンで新しいエージェントを登録できてしまう不具合を修正。
  5.1 節に、名前への新しい発行は以前の未使用トークンをすべて無効化すること、エージェントの削除は発行済みの未使用トークンも合わせて無効化することを追記。
  登録済みの名前へ有効なトークンで登録しようとした場合の応答も、生の SQL 誤りではなく専用の誤り(HTTP 409)に変更
