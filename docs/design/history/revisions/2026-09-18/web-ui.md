# 2026-09-18: web-ui

- ルールの分割と統合を Web UI に持ち込む(2026-09-18):それまで `rule split` と `rule merge` は CLI にしかなく、対象の ID を探すのも人手だった。
  10.1 節に、詳細ページの分割・統合の 2 区画と、5.4 節に統合の条件(エージェント、プロトコル、方式、隣接、実効宛先の連続に加え、PROXY protocol・拒否/許可リスト・レート・enabled の一致)と `id1` の ID が残る規則を明記した。
  組み立てと検査は `proto.Rule.Split` と `proto.Merge`/`proto.FindMergeBlocker` に移し、CLI と Web UI で共有する。
  これに伴い `rule merge` の実装を、これまで検査していなかった PROXY protocol・拒否/許可リスト・レート・enabled の一致も見るように改め、統合後に残る ID を(隣接ポートの小さい方でなく)常に `id1` にした。
  ヘルプ文面(`rule merge` の Long)は変更前から「lists and limits must be the same」「keeps the ID of <id1>」と書いていたため、これは実装をヘルプの記述に合わせた修正であり、CLI の使用者から見た約束は変わらない。
  ラボで、カーネルモードとユーザー空間モードの両方で、UDP の範囲ルールを Web UI(`curl` で `/ui/rules/{id}/split` と `/merge` を叩く形)で分割・統合する間、client から流した UDP のセッションが切れないことを確認した

- ルール全体の書き出しと読み込みを Web UI に持ち込む(2026-09-18):それまで VPS の移転などでルール全体を書き換えるには `rule ls --json | jq .rules > rules.json` と `rule import` を CLI で使うしかなく、中身を見ずに実行すると転送が止まる事故があり得た。
  10.1 節に、書き出し(`GET /ui/rules/export`)と、まだ適用せず差分の確認ページを出す読み込み(`POST /ui/rules/import`、`/ui/rules/import/apply`)を追記した。
  差分の計算(追加・変更・削除・変わらないの判定とフィールドごとの説明)は `proto.DiffRules` に、削除対象の抽出は `proto.DeletedIDs` に切り出し、CLI の `rule import` も独自の突き合わせをやめてこの 2 つを使う形に改めた。
  未登録のエージェントを指すルールと `Rule.Validate` に落ちるルールは確認ページに列挙し、適用ボタンを出さない。
  適用は、確認ページを描いた時点の世代と、ルール集合全体のハッシュ(`proto.RulesDigest`、ID でソートしてから JSON にすることで並び順の違いを無視する)を hidden で送り、適用の直前にどちらかが今の値と違えば何も変えずに再アップロードを求める。
  group/note/接続元制限/レートだけの変更は世代を上げない(5.3 節)ため、世代だけの照合ではこの種の食い違いを見逃すので、ハッシュも見る必要がある。
  ラボ(カーネルモード)で、UI の書き出しを CLI の `rule import` が読めること、CLI の `rule ls --json` の配列を UI の読み込みがそのまま「変わらない」と判定すること、1 件の削除を含むファイルの確認ページに削除が出て適用するまで何も変わらないこと、確認ページを描いた後に CLI の `rule set --note`(世代を上げない変更)を挟むと適用が拒否されること、やり直して適用すると削除が反映され、残るルールの UDP 転送が続くことを確認した。
  同じ確認を userspace モードでも行った

- ダッシュボードの単一カラム化(2026-09-18):それまでの左右 2 カラム(本体とエージェント/ルールが左、警告と適用中のファイアウォール設定が右)は、右側が縦に長くなるルール数の多い環境で本体より先に切れて見えづらかった。
  10.1 節を、上から順にサーバー情報・警告・エージェント一覧・ルール一覧・ファイアウォール設定を並べる 1 カラムに改めた。
  警告は 0 件のとき何も表示せず場所を取らないが、5 秒ごとの部分更新の受け皿の要素は残し、ヘッダの全体ヘルスの隣に件数を出してバナーへリンクする形にした。
  ファイアウォール設定は全幅にして既定で折りたたむようにした。
  表示レイアウトだけの変更なのでラボは使わず、Web UI のレンダーテストで警告 0 件・1 件以上それぞれの表示を確認した
