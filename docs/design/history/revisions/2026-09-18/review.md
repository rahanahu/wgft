# 2026-09-18: review

- エージェント用 API の HTTP/2 を無効化(2026-09-18):11 節に、TLS 1.2 以上かつ HTTP/1.1 だけで応じること、鍵交換の曲線は Go の既定に従うことを追記

- 背景説明を README と整合(2026-09-18):Pangolin から着想を得たこと、raw TCP/UDP に特化した理由、日本の IPv4 over IPv6 回線で任意の受信 IPv4 ポートが使えない場合を背景として明記し、特定製品の不具合を原因とする表現を削除。

- OOM からの復帰と `MemoryMax=` の例(2026-09-18):10.3 節に、OOM で殺された `vpsd` が `Restart=on-failure` で戻ること、ホスト全体の OOM では別のプロセスが選ばれうることを書き、unit に `MemoryMax=` の例を既定では無効のコメントとして添えた。
  ラボで同梱の unit を動かし、小さい `MemoryMax=` では OOM で殺されても自動で起動し直して攻撃の後すぐに転送が戻ること、300M では既定の上限の攻撃に耐えることを確認した。
  未確認:`agent.service` での同じ設定

- `server.env` の権限の問題を修正(2026-09-18):同梱の unit は `DynamicUser=yes` で動くため、旧い手順の 0600 では読み取れず、再起動を繰り返すことをラボで確認した。
  `server.env` は秘密を含まない設計として 0644 に変更し、読めない設定ファイルは終了コード 3 で停止する。
  読めない場合の直し方は、ファイル名ではなく server と agent のコマンドが添える(11a 節)

- `agent.service` に `RestartPreventExitStatus=3` を追加(2026-09-18):読めない `agent.env` で再起動を繰り返すこと、修正後は設定の誤りとして停止し、正しい `root:wgft` の 0640 では正常に起動することを確認した

- SQLite のファイルの権限(2026-09-18):9 節に、本体を 0600 で作り、既存の本体と WAL の補助ファイルからグループとその他の権限だけを起動時に外すこと、`server check` は読み取り専用で開いて何も変えないことを追記した。
  `server check` は補助ファイルが無ければ `immutable=1`、あれば `mode=ro` で開く。
  `mode=ro` だけでは SQLite が補助ファイルを作って残すためである
