# 2026-09-18: admission-policy

- レート制限の欄の言い直し(2026-09-18):利用者がパケット制限を接続数の制限と読み違えたため、10.1 節のレート制限の記述を改めた。
  `per_source_rate` と `new_flow_rate` の見出しを「新しい接続」に言い直し、数えるのは新しい接続(TCP のコネクションか、UDP の初めて見た送信元アドレスとポートの組)であって開いている接続を数えないことを明記した。
  `packet_rate` は通信中のデータも含めて数えることを見出しに添え、誤読しやすいため区画を折りたたみ、値が入っているときだけ開く形にした。
  値が入っている欄には読み上げの一文を添え、区画の見出しにはこのルールの累積 drop 数を一覧と同じ値で出す。
  表示文言だけの変更なのでラボは使わず、Web UI のレンダーテストで ja/en 双方の文言を確認した
