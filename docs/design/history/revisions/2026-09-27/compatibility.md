# 2026-09-27: compatibility

- Windows のエージェントを Windows 11 の実機で確かめ、確かめた範囲を 7a.11 節の保証に含めた(2026-09-27、GitHub issue #280、所有者の決定):v1.2.0 のリリースのバイナリを、Windows 11 Pro(25H2、amd64)の実機で管理者でない利用者として動かし、別のホストのカーネルモードの v1.2.0 の server に対して確かめた。
  回線は有線の Ethernet である。
  確かめた範囲は、登録、Windows 自身と LAN の別のホストへの TCP と UDP の転送、server の停止と再起動をまたぐ stream の再接続、スリープからの復帰、ネットワークアダプタを無効にして有効に戻した後の復帰、`agent doctor`、鍵の操作である。
  2026-09-22 の項がおもな理由に挙げた 5.2 節の ping/pong による生死の判定が stream を切ったのは、記録したログでは、スリープからの復帰の直後の 1 回だけだった。
  その後 stream は再接続した。
  7 節の watchdog は、約 2 分のスリープでは作り直さず、約 11 分 32 秒のスリープの後に 1 回だけトンネルを作り直した。
  この挙動から、Windows の `InterruptTime` がスリープの時間を含むことを確かめた(7 節)。
  時計そのものを測るプログラムは流していない。
  Wi-Fi の切断と切り替え、ユーザー空間モードの server の停止をまたぐ UDP の受信は実施しておらず、issue #280 に残す。
  7a.11 節は Windows の agent の確かめた範囲を保証に含め、範囲の外の挙動と macOS の agent を暫定のままとした。
  10.2c 節の Windows についての記述も合わせて直した。
