  `agent ls` の GEN も報告された番号と説明する。
  単体テストでは、番号が一致したときの所見、遅れたときの判定、一覧の制約の表示を確かめた。
  ラボのカーネルモードでは、実際に接続したエージェントの番号が一致しても `server doctor --json` の所見が内容を UNKNOWN と示すことを確かめた。
