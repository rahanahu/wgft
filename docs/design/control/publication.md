# 全体状態の配信

server はエージェントごとの全体状態を配ります。
保存済みの宣言と、転送面へ適用に成功した配信用の写しを区別します。


配信:

- `vpsd` は接続直後と、そのエージェントに配る内容が変わるたびに、全体状態を送る。
  差分ではなく全体を送る
- 全体状態はエージェントごとに組み立てる。
  そのエージェントを持ち主とするルールだけが入る([5.3 節](rules.md#53-ルールのスキーマ)の `agent`)
- 全体状態は 1 通のメッセージで送る。
  エージェントが読む 1 通の大きさの上限は 4 MiB で、これを超える全体状態をエージェントは読めません。
  この上限と、確立した stream で `vpsd` が読む 1 通の上限(1 MiB、上記)が、エージェントあたりのルールの数の上限と、ルールの ID と `target` の長さの上限([5.3 節](rules.md#53-ルールのスキーマ))の根拠です
- 世代はエージェントごとの値ではなく、ルール集合全体に対して 1 つの値です。
  どれか 1 つのエージェントに配る内容が変われば 1 つ上がり、`vpsd` は接続中の全エージェントへ配り直す。
  配る内容が変わらないエージェントは、同じ内容を新しい世代で受け取ります
- 適用が成功した後に `vpsd` が配り直すのは、配信用の写し(次項)が直前の写しと違うエージェントだけです。
  世代が上がれば全エージェントの写しが変わるので、ルールの変更は全エージェントに届く。
  鍵の宣言は世代を上げず、宣言したエージェントの写しの鍵だけを変えるので、他のエージェントには配らない。
  宣言したエージェントの新しい接続は、接続時の全体状態を受け取ります。
  無効化は保存の確定時に世代を上げ、全エージェントへ配る
- 1 つの全体状態の世代、ルール、エージェントの無効の印は、転送面の適用に使った宣言から組み立て、適用に成功したときに配信用の写しとして保持します。
  保存後の適用に失敗した宣言は、接続時や後から動く配信処理でもこの写しに混ぜない。
  無効化だけは保存の確定時に対象の無効の印とルールの停止、世代を先に反映します。
  登録を削除したら、その登録の写しは後の適用が失敗しても直ちに配信対象から外す。
  送信する接続ごとに写しを選び、接続固有の版の情報はその写しを変更せずに加えます。
  接続はトークンを認証した時点の登録 identity を保持し、鍵の保存と State の選択で現在の登録 identity と照合します。
  認証後、最初の鍵の受信前に登録を削除して同じ名前で登録し直しても、旧接続は新しい登録を変更できません。
  接続の鍵は配信用の写しの鍵とも照合し、保存後の適用に失敗した新しい鍵の接続は旧接続を置き換えない。
  旧接続は成功済みの鍵で無効化の停止を受け取れます。
  送信済みの状態をエージェントが適用したことは、この選択と送信だけでは確認できません
- 新しい鍵を保存した後の適用が失敗している間、同じ登録の恒久トークンと最後に成功した鍵で再接続したエージェントは、その鍵に対応する配信用の写しを一時的に受け取れます。
  この再接続は保存済みの新しい鍵を書き戻さず、無効化の停止も受け取ります。
  新しい鍵の全体適用が成功したら旧鍵の接続を退役させ、旧鍵に新しい写しを配らない。
  新しい鍵の接続は、その成功後に最新の写しを受け取ります
- 配信要求は接続ごとに 1 件だけ保留し、連続した要求は 1 回の最新状態の送信にまとめる。
  接続ごとの送信処理は接続終了時に終わる。
  新しい State は、その接続の送信権を得た後に配信用の写しを選ぶ。
  無効化や登録削除の確定後に新しく選ぶ State は停止または削除を反映します。
  確定前に選択を始めた送信は既に進行中なので、送信途中の内容を遡って取り消すことはできません。
  接続の差し替え後、旧接続で既に進行中の送信は完了するか失敗し、新接続は自身の初回 State を選ぶ
- 世代の比較は同一 WebSocket 接続内に限る。
  接続直後の最初の全体状態は世代に関わらず必ず適用し、以後は手元より古い世代を捨てます。
  `vpsd` の再構築やバックアップからの復元で世代が巻き戻っても、これで収束します
- 接続直後の最初の全体状態より後に届いた全体状態が、手元で最後に適用に成功した全体状態と世代も中身も同じなら、エージェントは適用し直さない。
  トンネルが立っていて、試し直しを待つ全体状態も、拒んだ wg 設定も無いときに限る。
  旧い版の `vpsd` は他のエージェントの鍵の変更でも全体状態を配り直し、カーネルモードのエージェントはそのたびに wgft0 の収束、テーブルの差し替え、宛先への試し接続をやり直していたためです。
  同じ世代でも中身が違えば適用します。
  `vpsd` は UDP のタイムアウトの値を、世代を上げずに配信用の写しへ書き込むことがあるためです
- エージェントは全体状態を「宣言された状態に収束させる」方式で適用します。
  wg 設定が変わればトンネルを張り直し、リスナーは変わったものだけを開閉します。
  収束の単位は [7 節](../agent-dataplane.md#7-データプレーン自宅側)に定める。
  カーネルモードのエージェントの収束は [7b 節](../agent-kernel.md#7b-データプレーン自宅側カーネルモード)に定める
