### 複数サービスへの配り方

1 拠点のエージェントから、ルールごとに異なる LAN のホストへ転送できます。


エージェントは `target` へ自分から接続するので、宛先はサービスと同じホストでなくてよい。
1 拠点に 1 つのエージェントを置き、ルールごとに `target` を各ホストへ向けるのが基本形です。

```
wgft rule add --agent home --udp 2456-2457 --to 192.168.1.20:2456
wgft rule add --agent home --udp 2458-2459 --to 192.168.1.21:2456
wgft rule add --agent home --tcp 25565     --to 192.168.1.22:25565
```

同じサービスを複数台動かす場合は、VPS 側の `listen_port` をずらし、`target` 側で本来のポートに写す(上の例の 2458 から 2456 への写し替え)。

ホストごとにエージェントを置く構成も同じ仕組みで動く。
ホスト間で到達性がない場合や、片方の停止をもう片方に波及させたくない場合に使います。
