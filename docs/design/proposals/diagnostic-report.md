#### `--report` の設計上の約束

--report は未実装の提案です。
報告専用の許可一覧の型を使い、内部構造を丸ごと直列化しない方針を定めています。


`--report` は、GitHub の Issue にそのまま貼れる形を出す将来の選択肢です。
この版では実装しないが、後から加えるときに出力の形を変えずに済むよう、原則を先に定める。
`--report` は許可一覧であり、伏せ字ではありません。
内部の構造をそのまま直列化してから秘密を取り除く形にはしません。
報告専用の型 (版、OS、モード、エージェントの状態、ルールの状態など) を明示的に埋める形にし、後から加えたフィールドが既定で漏れるのではなく既定で現れないようにします。
今の診断が読む値には、秘密鍵も恒久トークンも接続文字列も含まれない。
管理用 API のうち診断が呼び出す 3 つの節点がそれらを返さないためです。
