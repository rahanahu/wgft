# 送信元の制限とモードの選択

ユーザー空間モードでは、自宅サービスから見た接続元はエージェントのアドレスです。
`vpsd` と Linux のエージェントにはカーネルモードを推奨し、ユーザー空間モードはカーネルモードを使えない環境のための代替とします。
互換性を保つため、エージェントの既定は root 権限を要しないユーザー空間モードのままです。



接続元 IP ごとの上限は、少数の IP からフローを保持してルールの上限を埋め、正規の利用者を締め出す攻撃を防ぐ。
送信元を偽装できる UDP では、この攻撃は防げない。
カーネルモードの VPS にも、[6.1 節](../vps/kernel.md#61-カーネルモード)の `ct count` による同じ設定値の上限があります。
この上限はプロセス全体の上限と連動しません。
プロセス全体の上限を上げても既定値(256、128)のまま変わらないので、メモリに余裕がある VPS でプロセス全体の上限を上げて同時フロー数を増やしたい運用者は、接続元 IP ごとの上限も明示して上げる必要があります。

ユーザー空間モードでは、サービスから見た接続元は常にエージェントのアドレスになります。
カーネルモードの見え方は [7b.2 節](../kernel-agent/targets.md#7b2-宛先の扱い)に書きます。

## モードの推奨と既定

VPS の `vpsd` とエージェントのモードは、次のように位置付けます(2026-10-17、所有者の決定)。
2026-09-24 の所有者の決定では、エージェントのカーネルモードを、エージェントの停止中も転送を続けたい Linux のホストのための選択肢としていました。
この決定で、Linux のエージェントにはカーネルモードを推奨します。
エージェントの既定のモードと、`WGFT_MODE=kernel` の明示によるカーネルモードの選択は変わりません。

| | 推奨 | 代替(保証が弱い) |
|---|---|---|
| VPS の `vpsd` | カーネルモード | ユーザー空間モード: root 権限のない VPS、Docker |
| 自宅側のエージェント | Linux のカーネルモード | ユーザー空間モード: Windows、macOS、root 権限のない Linux |

`vpsd` にカーネルモードを推奨する理由は、設定した転送をカーネルが行い、公開ポートの通信がユーザー空間の netstack を通らないためです。
プロキシモード([6.2 節](../vps/proxy.md#62-プロキシモード))以外のルールの通信は、`vpsd` の中継も通りません。
カーネルモードでは、`vpsd` の停止中もプロキシモード以外のルールの転送が続きます([10.3 節](../operations/setup.md#103-運用の流れ))。
プロキシモードのルールは `vpsd` のプロセスが中継するので、`vpsd` が止まると転送も止まります。

Linux のエージェントにカーネルモードを推奨する理由は、エージェントの停止中や更新の間も転送が続き、通信がユーザー空間の netstack を通らないためです。
カーネルが転送するので、中継のプロセスの処理能力にも依りません。

ユーザー空間モードでは、プロセスが止まると転送も止まります。
ユーザー空間モードの制約は[ユーザー空間の転送と資源](README.md)の各仕様に定めます。

ユーザー空間モードは、`vpsd` とエージェントの両方で代替として保守します。
必要とする利用者がいるためです。
サービスを動かす PC が Windows か macOS の 1 台だけの利用者は、その PC でエージェントを動かします。
`vpsd` を root 権限なしで動かす利用者や、Docker で動かす利用者もいます。

エージェントの既定はユーザー空間モードのままとし、カーネルモードは `WGFT_MODE=kernel` を明示したときだけ使います。
既定を保つ理由は、既定を変えると公開の挙動が変わることと、Windows と macOS ではユーザー空間モードしか動かないことです。
ユーザー空間モードは root 権限を要せず、自宅側に nftables と `ip_forward` の設定を要求しません。
[6.1 節](../vps/kernel.md#61-カーネルモード)と同じ他チェーンとの干渉問題も、自宅側に持ち込みません。
性能面でも、想定する用途(ゲームサーバの UDP、数 Mbps)に対して netstack の処理能力は十分に余裕があります。
カーネルモードの干渉問題には、[6.1 節](../vps/kernel.md#61-カーネルモード)と同じく他のテーブルとホストの設定を検査して提示し、自動では書き換えない方法で答える([7b 節](../agent-kernel.md#7b-データプレーン自宅側カーネルモード))。
